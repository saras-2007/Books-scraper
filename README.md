
# Books to Scrape - Web Scraping Project

## Objective
To collect book information from a practice website
using Python and BeautifulSoup.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Data Collected
- Book title
- Book price
- Book rating
- Availability

## Process
1. Access the website.
2. Parse HTML using BeautifulSoup.
3. Extract book details.
4. Navigate through catalogue pages.
5. Save the data in CSV format.
6. Clean and verify the dataset.
7. Analyze and visualize the data.

## Output Files
- books.csv
- cleaned_books.csv
- rating_distribution.png
- book_price_distribution.png

## Conclusion
The project demonstrates how to scrape, clean,
analyze, and visualize book data using Python.
